
# API Documentation for [clincly]

## Overview

This API provides CRUD (Create, Read, Update, Delete) operations for managing services in a database. It allows clients to:

List all services (GET /dataservice)

Get a specific service (GET /dataservice/{id})

Create a new service (POST /dataservice)

Update an existing service (PUT /dataservice/{id})

Delete a service (DELETE /dataservice/{id})

## Base URL
http://localhost:8000/dataservice
